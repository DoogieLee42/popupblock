Can You Allow Pop-ups for Just One Site on iPhone?

You need one site's pop-up, maybe a bank, a school portal or a payment page, but you don't want every site's pop-ups. On a Mac that's a two-click setting. On iPhone, it isn't there.

The short answer: not in Safari's settings

Settings › Apps › Safari › Block Pop-ups is one switch for every website. Safari's per-site settings (the page menu › Website Settings) cover things like desktop mode, camera, microphone and location, but not pop-ups.

Workarounds that do work

  1. Tap the button again. Safari allows a window that opens right after a tap. If the first tap didn't open it, the page may have opened it a moment later (which gets blocked); a second tap often goes through.
  2. Turn the blocker off for a minute. Settings › Apps › Safari › Block Pop-ups off, finish the task, then switch it back on. Easy to forget, so do it right away.
  3. Use the site's app. Banks, schools and payment services usually have an app that handles verification without pop-ups.
  4. Request the desktop site. Page menu › Request Desktop Website. Some sites open their login in the same tab on desktop instead of a pop-up.
  5. Use an extension that allows per site. A pop-up blocking Safari extension can do what the built-in setting can't: block by default, but let you open one window or always allow one site.

Why keep the blocker on at all?

With Block Pop-ups off, every site can open windows on its own: fake "virus detected" pages, prize pages and app-install prompts. Leaving it on and allowing exceptions is safer than leaving it off for good.
