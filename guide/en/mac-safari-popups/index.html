Safari Blocked a Pop-up on Mac? How to Allow It for One Site

On a Mac, Safari lets you decide pop-ups site by site, so you never have to switch the blocker off for everything. Here's how to let one window through, or one site, in under a minute.

Open the window Safari just blocked

  1. Look at the right side of the address bar. When Safari blocks a pop-up and the site is set to Block and Notify, a small pop-up icon appears there.
  2. Click the icon to open the blocked window.
  3. No icon? The site is set to Block, which blocks silently. Change it to Block and Notify or Allow (below), then try the button again.

Allow pop-ups for one website

  1. Open the website in Safari.
  2. Choose Safari › Settings (or press ⌘,) and click the Websites tab.
  3. Select Pop-up Windows in the sidebar.
  4. Find the site under "Currently Open Websites" and set it to Allow.

The setting is saved for that site. It moves to the "Configured Websites" list once you close the tab, and you can change or remove it there later.

Change the default for every other site

At the bottom of the same Pop-up Windows screen, "When visiting other websites" sets what happens on sites you haven't configured. Block and Notify is the best default: unwanted pop-ups stay closed, and you can still open a legitimate one with a click.

The setting doesn't seem to work

  • Wrong site in the list. Sign-in and payment windows often open from a different domain than the page you're on (for example a bank's verification domain). Allow the site you started from, and if the window comes from another domain, allow that one too once it appears in the list.
  • An extension is blocking it. Content blockers and pop-up extensions run on top of Safari's setting. Check Safari › Settings › Extensions, or allow the site inside the extension.
  • Screen Time limits. If Content & Privacy restrictions are on, some web content can be blocked regardless of Safari settings.
  • Reload the page after changing the setting; it applies to new page loads.

On iPhone and iPad it's different

Safari on iPhone and iPad has a single on/off switch for every site, with no per-site setting. See How to Allow or Block Pop-ups in Safari on iPhone and Mac and Can you allow pop-ups for just one site on iPhone?
