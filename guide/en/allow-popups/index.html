How to Allow or Block Pop-ups in Safari on iPhone and Mac

Blocking pop-ups is the right default, but sometimes a bank, payment or sign-in page needs one. Here's where the setting lives on each device, and how to let through only the window you need.

iPhone and iPad

  1. Open Settings.
  2. Go to Apps › Safari (on iOS 17 and earlier, Settings › Safari).
  3. Under General, turn Block Pop-ups off to allow pop-ups, or on to block them.

There is no per-site pop-up setting on iPhone. The switch applies to every site. Website Settings in the page menu only covers things like desktop mode, camera, microphone and location.

Mac (per-site control)

  1. In Safari, choose Safari › Settings and open the Websites tab.
  2. Select Pop-up Windows in the sidebar.
  3. For each open site, choose Block and Notify, Block or Allow. "When visiting other websites" sets the default.
  4. With Block and Notify, Safari shows an icon in the address bar when it blocks a window; click it to open that window.

Getting one blocked window open on iPhone

  1. Tap the button again. Safari allows windows opened right after a tap, so a second tap often works.
  2. Turn Block Pop-ups off briefly, finish the task, then turn it back on.
  3. Use the bank's app if it has one; verification steps tend to be smoother there.

Still getting ad pop-ups with Block Pop-ups on?

Modern ads open at the moment you tap, so Safari treats them as windows you asked for. Blocking those takes a Safari extension that checks each tap. A good one also handles the problem above: it lets you open a blocked window once, or always allow a trusted site, which the iPhone setting can't do.
