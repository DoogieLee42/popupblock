Safari 팝업 차단을 켰는데도 광고 창이 뜨는 이유

설정에서 팝업 차단을 분명히 켜 두었는데, 어떤 사이트에서는 누를 때마다 광고 창이 뜹니다. 팝업 차단이 고장 난 걸까요? 아닙니다. 팝업 차단이 원래 막지 못하는 종류의 광고이기 때문입니다.

팝업 차단이 막는 것

Safari의 팝업 차단(설정 › 앱 › Safari › 팝업 차단)은 사용자가 아무것도 누르지 않았는데 페이지가 스스로 여는 창을 막습니다. 페이지를 열자마자 뜨는 창, 몇 초 뒤 저절로 뜨는 창이 여기에 해당합니다. 예전에는 이런 광고가 대부분이었고, 지금은 이것만큼은 거의 확실하게 막힙니다.

팝업 차단이 막지 못하는 것

Safari는 사용자가 화면을 누른 직후에 열리는 창은 사용자가 원한 것으로 보고 열어 줍니다. 로그인 창, 결제 창, "새 탭에서 열기" 같은 정상적인 기능이 모두 이 방식이기 때문입니다. 요즘 광고는 바로 이 틈을 노립니다.

  1. 보이지 않는 막
    화면 전체에 투명한 링크를 덮어 둡니다. 재생 버튼을 누른 것 같지만 실제로는 광고 링크를 누른 것입니다.
  2. 누르는 순간 바꿔치기
    평범한 링크처럼 보이지만, 누르는 순간 스크립트가 주소를 광고 주소로 바꿉니다.
  3. 자기 주소로 포장한 광고
    사이트 자신의 주소로 새 창을 연 뒤 그 안에서 광고 사이트로 넘깁니다. 같은 사이트 창이라 의심을 피합니다.
  4. 탭 바꿔치기
    새 탭에는 원래 보던 페이지를 띄우고, 원래 탭은 광고 사이트로 바꿉니다. 닫고 돌아오면 보던 페이지가 광고로 바뀌어 있습니다.
  5. 차단 뒤 새로고침
    광고 창이 막히면 보던 페이지를 새로고침해서 영상을 처음으로 되돌립니다. 다시 누르게 만들기 위해서입니다.

모두 "사용자가 누른 순간"에 일어나기 때문에 Safari의 팝업 차단 입장에서는 정상적인 동작과 구분하기 어렵습니다.

그럼 어떻게 막나요

설정만으로는 위 다섯 가지를 막을 수 없습니다. 페이지 안에서 누른 대상이 정말 링크인지, 열리는 주소가 누른 것과 같은지를 확인해야 하는데, 이건 페이지 안에서 동작하는 Safari 확장 프로그램만 할 수 있습니다.

배너를 지우는 일반 광고 차단기는 광고 서버 목록을 기준으로 차단해서, 목록에 없는 새 광고 주소나 사이트 자기 주소로 포장한 광고는 놓치기 쉽습니다. 이런 증상에는 새 창과 페이지 이동 자체를 감시하는 확장이 맞습니다.

PopupBlock

누르지 않은 광고 새 창과 탭 바꿔치기를 Safari에서 막는 확장 프로그램입니다. 직접 누른 링크와 로그인·결제 창은 그대로 열립니다. 개인정보는 수집하지 않습니다.

PopupBlock은 무료로 1번(보이지 않는 막)과 아무 데나 눌러도 뜨는 광고 새 창·새 탭을 막고, Pro(한 번 결제)는 2~5번(바꿔치기 링크, 포장된 광고, 탭 바꿔치기, 차단 뒤 새로고침)까지 막습니다. 처음 7일은 Pro를 무료로 써 볼 수 있습니다. 필요한 창이 막혔다면 화면 아래 알림에서 "이번만 열기"를 누르면 됩니다.

자주 묻는 질문

팝업 차단을 꺼야 하나요?

아니요. 켜 두세요. 저절로 뜨는 창은 여전히 막아 주고, 확장 프로그램과 함께 써도 충돌하지 않습니다.

사이트를 "항상 허용"으로 두면 광고도 열리나요?

PopupBlock에서 항상 허용한 사이트는 검사하지 않으니 광고도 열립니다. 은행·쇼핑처럼 믿을 수 있는 사이트만 허용하세요.

광고 새 탭 말고 다른 증상도 있어요.
