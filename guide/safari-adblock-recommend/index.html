아이폰 사파리 광고 차단 앱 추천: 무엇을 막고 싶은지부터 고르세요 (무료 포함)

"사파리 광고 차단 추천"을 검색하면 앱 이름만 줄줄이 나옵니다. 그런데 광고 차단 앱은 종류마다 막는 대상이 달라서, 내가 겪는 문제에 맞는 종류를 고르지 않으면 설치하고도 "왜 안 막히지?" 하게 됩니다.

1단계: 무엇이 문제인가요?

A. 페이지에 배너·동영상 광고가 너무 많다

→ 콘텐츠 차단기(광고 차단기)가 맞습니다.

B. 누를 때마다 광고 새 창·새 탭이 열리거나, 엉뚱한 사이트로 넘어간다

→ 팝업·리다이렉트 차단 확장이 맞습니다. 콘텐츠 차단기로는 잘 안 막힙니다.

C. 광고가 나를 따라다니는 게(추적) 싫다

→ Safari 기본 기능 + 콘텐츠 차단기.

D. 앱(네이버·유튜브 앱 등) 안의 광고를 없애고 싶다

→ Safari 확장으로는 불가능합니다. Safari 확장은 Safari 안에서만 동작합니다.

2단계: 돈 안 드는 것부터 켜기 (무료)

  1. 팝업 차단: 설정 › 앱 › Safari › 팝업 차단 켜기. 누르지 않았는데 저절로 뜨는 창을 막습니다.
  2. 사기성 웹 사이트 경고: 같은 화면에서 켜기.
  3. 추적 방지: 같은 화면 › 고급에서 "교차 사이트 추적 방지"가 켜져 있는지 확인.
  4. 읽기 도구: 글 위주 페이지는 주소창 페이지 메뉴 › 읽기 도구 보기로 광고 없이 볼 수 있습니다.

이것만으로 해결되면 앱은 필요 없습니다. 하지만 B처럼 "누를 때마다" 열리는 광고는 이 설정으로 막히지 않습니다(이유).

3단계: 종류별로 고르는 기준

콘텐츠 차단기 (배너·추적)

AdGuard, 1Blocker 같은 앱이 여기에 속합니다. 광고 주소 목록을 받아 두고 그 목록의 광고를 불러오지 않게 합니다. 고를 때 볼 것:

  • 목록이 자주 갱신되는가 (오래된 목록은 새 광고를 못 막음)
  • 한국 사이트용 필터가 있는가
  • 무료 범위와 유료 범위가 명확한가

팝업·리다이렉트 차단 확장 (새 창·납치)

주소 목록이 아니라 동작을 봅니다. 사용자가 진짜 링크를 눌렀는지, 열리는 주소가 누른 것과 같은지, 새 탭이 열린 직후 보던 탭이 다른 곳으로 가는지를 확인합니다. 고를 때 볼 것:

  • 오탐 대처: 은행·결제·로그인 창까지 막히면 결국 끄게 됩니다. 막힌 창을 바로 여는 버튼이 있는가
  • 막는 수법의 범위: 새 창만인지, 탭 바꿔치기·자동 이동까지인지
  • 개인정보: App Store의 "앱 개인정보" 항목에서 수집하는 데이터가 없는지
  • 직접 확인: 데모 페이지 같은 곳에서 실제로 막히는지 눌러 볼 수 있는가

함께 써도 되나요?

됩니다. 콘텐츠 차단기와 팝업·리다이렉트 차단 확장은 동작 방식이 달라 충돌하지 않고, 서로 빈틈을 메웁니다. 배너는 콘텐츠 차단기로, 새 창·납치는 팝업 차단 확장으로 막는 조합이 가장 깔끔합니다. 자세한 차이는 광고 차단기와 팝업 차단기는 무엇이 다른가에 정리했습니다.

PopupBlock

누르지 않은 광고 새 창과 탭 바꿔치기를 Safari에서 막는 확장 프로그램입니다. 직접 누른 링크와 로그인·결제 창은 그대로 열립니다. 개인정보는 수집하지 않습니다.

PopupBlock은 B 문제를 위한 팝업·리다이렉트 차단 확장입니다. 광고 새 창·새 탭과 투명 링크는 무료로 막고, 탭 바꿔치기·포장된 광고·차단 뒤 새로고침·바꿔치기 링크·저절로 광고로 넘어가는 접속 납치·가짜 닫기 버튼은 Pro(한 번 결제, 7일 무료 체험)가 막습니다. 아이폰과 아이패드에서 모두 쓸 수 있습니다. 막힌 창은 알림에서 "이번만 열기"로 바로 열 수 있고, 어떤 데이터도 수집하지 않습니다.
