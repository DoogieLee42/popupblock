사파리 팝업 차단 해제·허용 방법 (아이폰·맥북)

팝업 차단은 켜 두는 것이 기본입니다. 그런데 은행 인증, 결제, 로그인 창처럼 꼭 필요한 창까지 막힐 때가 있어서, 어디서 켜고 끄는지와 필요한 창만 여는 방법을 알아 두면 편합니다.

아이폰·아이패드에서 켜고 끄기

  1. 설정 앱을 엽니다.
  2. 앱 › Safari로 이동합니다. (iOS 17 이하는 설정 › Safari)
  3. 일반 항목의 팝업 차단을 켭니다(초록색). 기본값은 켜짐입니다.

아이폰 Safari에는 사이트별 팝업 허용 설정이 없습니다. 켜면 모든 사이트에서 막히고, 끄면 모든 사이트에서 열립니다. 페이지 메뉴의 웹사이트 설정에는 데스크탑 버전, 카메라, 마이크, 위치 같은 항목만 있습니다.

맥에서 켜고 끄기 (사이트별 가능)

  1. Safari 메뉴 › 설정 › 웹 사이트 탭을 엽니다.
  2. 왼쪽 목록에서 팝업 윈도우를 선택합니다.
  3. 현재 열린 사이트마다 차단 및 알림, 차단, 허용 중 하나를 고를 수 있고, 아래의 "다른 웹 사이트 방문 시"로 기본값을 정합니다.

아이폰에서 필요한 창만 여는 방법

  1. 버튼을 한 번 더 누르기
    Safari는 직접 누른 직후 열리는 창은 허용합니다. 결제·인증 창이 안 열렸다면 버튼을 다시 눌러 보세요. 처음 누름이 다른 동작에 쓰인 경우가 많습니다.
  2. 잠깐 끄고 다시 켜기
    그래도 안 열리면 설정에서 팝업 차단을 잠깐 끄고 작업을 마친 뒤 다시 켭니다. 다시 켜는 것을 잊지 마세요.
  3. 은행·공공기관은 앱 사용
    인증 창이 많은 서비스는 전용 앱이 있다면 앱이 더 안정적입니다.

팝업 차단을 켰는데 광고 창이 뜬다면

요즘 광고는 여러분이 화면을 누른 순간을 이용해서 팝업 차단을 피합니다. 이 경우 설정으로는 막을 수 없고 Safari 확장 프로그램이 필요합니다. 자세한 원리는 팝업 차단을 켰는데도 광고 창이 뜨는 이유에 정리했습니다.

확장 프로그램을 쓰면 아이폰에 없는 사이트별 허용도 확장 안에서 해결할 수 있습니다. 예를 들어 PopupBlock은 막힌 창을 화면 아래 알림에서 이번만 열기로 바로 열고, 자주 쓰는 사이트는 이 사이트 항상 허용으로 빼 둘 수 있습니다. 로그인과 결제 창은 처음부터 허용되어 있습니다.

PopupBlock

누르지 않은 광고 새 창과 탭 바꿔치기를 Safari에서 막는 확장 프로그램입니다. 직접 누른 링크와 로그인·결제 창은 그대로 열립니다. 개인정보는 수집하지 않습니다.
