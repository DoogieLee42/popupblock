아이폰 Safari 확장 프로그램 설치하고 켜는 법

아이폰 Safari도 확장 프로그램을 쓸 수 있습니다. 다만 앱을 설치하는 것만으로는 동작하지 않고, 직접 켜고 권한을 허용해야 합니다. 이 단계에서 막히는 분이 많습니다.

1. App Store에서 설치

Safari 확장 프로그램은 일반 앱처럼 App Store에서 받습니다. 설치하면 홈 화면에 앱 아이콘이 생기는데, 이 앱은 대부분 설정 안내와 옵션 화면이고 실제 기능은 Safari 안에서 동작합니다.

2. 설정에서 켜기

  1. 설정 앱을 엽니다.
  2. 앱 › Safari › 확장 프로그램으로 이동합니다. (iOS 17 이하는 설정 › Safari › 확장 프로그램)
  3. 목록에서 설치한 확장을 누르고 확장 프로그램 허용을 켭니다.
  4. 아래 권한에서 모든 웹사이트를 허용으로 바꿉니다. 특정 사이트에서만 쓰고 싶다면 "확인"으로 두고 사이트마다 허용해도 됩니다.
  5. 개인정보 보호 브라우징에서도 쓰려면 개인정보 보호 브라우징 허용도 켭니다.

3. Safari 주소창에서 켜기 (다른 방법)

  1. Safari에서 아무 웹페이지나 엽니다.
  2. 주소창 왼쪽의 페이지 메뉴 아이콘을 누릅니다.
  3. 확장 프로그램 관리를 누르고 원하는 확장을 켭니다.
  4. 같은 메뉴에 확장 이름이 나타나면, 눌러서 이 사이트에서의 권한을 허용합니다.

"웹 페이지 내용을 읽을 수 있음" 안내가 무섭다면

권한을 허용할 때 Safari는 "이 확장 프로그램은 웹 페이지 내용을 읽고 변경할 수 있습니다"라고 안내합니다. 이 문구는 모든 Safari 확장에 똑같이 나오는 표준 안내입니다. 광고 창을 막거나 페이지를 바꾸려면 페이지 안에서 동작해야 하기 때문입니다. 걱정된다면 그 확장이 개인정보를 수집하는지 App Store의 앱 개인정보 항목과 개인정보 처리방침을 확인하세요.

켰는데 동작하지 않을 때

  • 이미 열려 있던 탭은 새로고침해야 적용됩니다.
  • 권한이 "확인"으로 되어 있다면 그 사이트에서 페이지 메뉴를 열고 허용했는지 봅니다.
  • 콘텐츠 차단기(광고 차단기)는 설정 › 앱 › Safari › 확장 프로그램 위쪽의 콘텐츠 차단기 항목에서 따로 켭니다.
  • 그래도 안 되면 Safari를 완전히 닫았다가 다시 열어 보세요.

예시: PopupBlock 켜기

PopupBlock은 설정 › 앱 › Safari › 확장 프로그램 › PopupBlock을 켜고 "모든 웹사이트"를 허용하면 바로 동작합니다. 앱을 열면 같은 안내가 나오고, 사이트별 설정은 Safari 페이지 메뉴의 PopupBlock에서 바꿀 수 있습니다. 방문 기록을 포함해 어떤 정보도 수집하거나 전송하지 않습니다.

PopupBlock

누르지 않은 광고 새 창과 탭 바꿔치기를 Safari에서 막는 확장 프로그램입니다. 직접 누른 링크와 로그인·결제 창은 그대로 열립니다. 개인정보는 수집하지 않습니다.
